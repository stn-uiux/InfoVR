🚀 ArcVRack 프로젝트 진행 보고서

작성일자: 2026년 8월 23일
프로젝트명: ArcVRack (3D Server Room Architecture)
버전: v1.6

1. 프로젝트 개요

ArcVRack은 데이터 센터 및 서버룸의 복잡한 물리적 인프라를 직관적으로 시각화하고 관리하기 위해 개발된 웹 기반 3D 서버룸 모델링 플랫폼입니다. 사용자는 웹 브라우저 상에서 서버 랙, 네트워크 장비, 물리적 구조물(벽, 파티션 등)을 자유롭게 배치하고 포트 연결 상태를 관리할 수 있습니다.

핵심 가치 (Core Value) 복잡하고 방대한 서버룸 인프라를 3D로 시각화하여, 관리자와 엔지니어가 물리적 위치와 연결 상태를 직관적으로 파악하고 효율적으로 운영할 수 있도록 돕습니다.

2. 사용된 기술 스택 (Tech Stack)

  • Core & UI: React 18, TypeScript, Vite
  • 3D Rendering: React Three Fiber (R3F), Three.js, @react-three/drei, Post-processing
  • State Management: Zustand (IndexedDB 및 LocalStorage 기반 영속성 아키텍처)
  • Styling & Assets: Vanilla CSS (CSS Variables 테마 시스템), Iconify
  • 3D Assets & Loading: GLTF/GLB 모델 파싱, Draco 압축 렌더링 지원
  • AI Integration: Gemini 3 Flash (포트맵핑 마법사 비전 분석 자동화)

3. 핵심 구현 기능 (Key Features)

📊 1. 계층형 인프라 관리 (Hierarchy Management)

  • 지역 / 센터 / 전산실 등 논리적, 물리적 계층 구조(Tree) 지원
  • 전산실(Node) 단위로 개별적인 3D 공간 및 장비 데이터를 완벽히 분리 및 격리

🏢 2. 3D 가상 공간 (CyberSpace) 구축 및 편집

  • 서버 랙, 기본 모델(벽면, 파티션, 책상 등) 배치 기능 지원
  • 외부 커스텀 에셋 임포트(GLB/GLTF)를 지원하여 공간에 즉시 적용 가능
  • 동적 가상공간(CyberSpace) 크기 조절, 실시간 라이팅(Light/Dark 3D Theme) 및 Post-processing(Bloom, AO) 효과 지원

🔌 3. 장비 및 포트 맵핑 (포트맵핑 마법사)

  • 장비 간의 포트 연결 상태와 헬스 상태(정상, 장애 등)를 직관적으로 시각화
  • AI 비전 기반 포트 인식: 장비 이미지를 자르고(Perspective Correction) Gemini AI를 통해 포트를 자동 탐지하는 마법사 페이지 분리 구현

📋 4. 모델 관리 및 썸네일 합성 파이프라인 (Model Registration)

  • 모듈러 장비 시스템: 섀시 SVG 위에 인터랙티브한 카드 그리드(병합/나누기/리사이징) 생성 및 슬롯 레이아웃(Uniform, Mixed, Row-based) 적용
  • 실시간 이미지 렌더링 파이프라인: 구성된 모듈(카드) 데이터를 기반으로 IndexedDB 캐싱을 활용해 실장도 전용 WebP 고화질 썸네일을 백그라운드에서 동적 합성 및 최적화하여 렌더링

4. 향후 추가 개발 항목

  • 장비 간 포트 링크 파인더: 포트를 선택하면 연결된 포트 정보를 3D 공간 상에서 직관적으로 하이라이팅 하여 보여주는 기능.
  • 고급 대시보드 통계: 전산실 내 유휴 자원(U공간), 소모 전력량 시뮬레이션 및 데이터 시각화 차트.
  • 장비 성능 위젯 표출: 특정 장비(서버, 스위치 등) 클릭 또는 호버 시 해당 장비의 실시간 상태 및 성능 데이터(CPU, Memory, Traffic 등)를 3D 화면 내에 플로팅 오버레이 형태의 위젯으로 즉각 표출하는 기능.
  • 전산실 온도 3D 시각화: 장비 및 랙 단위의 발열/온도 데이터를 연동하여 3D 공간 상에 히트맵(Heatmap) 형태로 시각화.
  • 실시간 공간 협업 에디터: 백엔드 웹소켓 통신을 이용해 여러 사용자가 동시에 3D 랙과 장비를 배치할 수 있는 기능.
