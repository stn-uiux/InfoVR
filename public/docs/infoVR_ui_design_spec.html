📐 InfoVR 화면설계서

버전: v1.0 | 작성일: 2026-08-19 | 관련 문서: 기능명세서 v1.5

1-1 메인 3D 뷰 (초기 화면)

화면 설명

본 화면은 메인 3D 뷰 (초기 화면) 기능과 관련된 동작 및 상태를 표시합니다. 주요 기능으로 [3D 서버실 전경, 카메라 조작(회전/줌/패닝), 방향키 이동, 전체보기 버튼 위치] 등을 포함하고 있습니다.

마커 드래그 이동 / 리사이징 (박스 우측 하단) / 삭제 (우클릭)

UI 요소 설명

1 3D 서버실 뷰어 3D Canvas
바닥·벽면이 렌더링된 메인 3D 공간. 마우스 드래그로 회전/패닝, 스크롤로 줌, 방향키로 카메라 이동 가능.
2 전체보기 버튼 Button
우측 카메라 큐브 아래 위치. 클릭 시 씬 내 모든 오브젝트가 화면에 최적 비율로 자동 맞춤됨.
3 Edit Mode / 테마 토글 Switch
우측 상단 툴바. Edit Mode ON/OFF 스위치로 수정 모드 진입, Light/Dark 토글로 테마 즉시 전환.

1-2 계층 구조 트리 (Hierarchy Tree)

화면 설명

본 화면은 계층 구조 트리 (Hierarchy Tree) 기능과 관련된 동작 및 상태를 표시합니다. 주요 기능으로 [좌측 사이드바 트리 구조, 노드 유형별 아이콘, 노드 클릭 시 씬 전환] 등을 포함하고 있습니다.

마커 드래그 이동 / 리사이징 (박스 우측 하단) / 삭제 (우클릭)

UI 요소 설명

1 좌측 사이드바 (계층 트리) Panel
지역 → 센터 → 전산실 등 계층 구조를 트리로 제공. 최상단 root부터 하위 zone까지 5가지 노드 유형 지원.
2 노드 유형 아이콘 Badge
트리 각 항목에 유형별(root/group/site/room/zone) 고유 아이콘이 표시되어 시각적 구분 제공.
3 노드 검색 Input / Form
트리 상단 검색창에서 노드 이름을 검색하여 대규모 인프라에서도 원하는 구역을 빠르게 탐색.
4 노드 클릭 → 씬 전환 Interaction
트리에서 노드를 클릭하면 해당 구역으로 3D 씬(카메라 시점)이 즉시 전환됨.
5 장비 리스트 Panel
트리에서 장비 토글을 클릭하면 해당 노드의 장비 리스트 표출.

1-3 랙 자동 포커싱 & 캐러셀

화면 설명

본 화면은 랙 자동 포커싱 & 캐러셀 기능과 관련된 동작 및 상태를 표시합니다. 주요 기능으로 [랙 클릭 → 카메라 이동 애니메이션, 하단 Focus Carousel UI, 캐러셀 내 랙 항목 구성] 등을 포함하고 있습니다.

마커 드래그 이동 / 리사이징 (박스 우측 하단) / 삭제 (우클릭)

UI 요소 설명

1 3D 랙 모델 군집 3D Object
배치된 랙들이 3D로 렌더링. 개별 랙 클릭 시 카메라가 부드럽게 해당 랙 정면으로 자동 이동(포커싱)됨.
2 Focus Carousel Navigation
하단 중앙의 랙 탐색 컨트롤. 전체 랙 개수·현재 순번 표시, 좌우 화살표로 순차 랙 포커싱 가능.
3 랙 포커스 라이팅 3D Effect
선택 랙 주변의 조명(PointLight) 강도가 증가하고 주변은 어두워져 선택 랙에 시각적 집중 제공.

1-4 에러 상태 대시보드 위젯

화면 설명

본 화면은 에러 상태 대시보드 위젯 기능과 관련된 동작 및 상태를 표시합니다. 주요 기능으로 [우측 Error Summary 4개 카드(Critical/Major/Minor/Warning), 카드 클릭 → Drill-down 테이블, 에러 항목 클릭 → 장비 포커싱] 등을 포함하고 있습니다.

마커 드래그 이동 / 리사이징 (박스 우측 하단) / 삭제 (우클릭)

UI 요소 설명

1 에러 요약 카드 (4종) Panel
Critical(빨강)·Major(주황)·Minor(노랑)·Warning(파랑) 등급별 에러 건수 카드. 클릭 시 Drill-down 테이블 오픈.
2 Drill-down 테이블 List
선택한 등급의 에러 항목을 목록으로 표시. 장비명, 포트, 에러 유형 등 상세 정보 포함.
3 에러 항목 클릭 → 포커싱 Interaction
테이블의 에러 항목 클릭 시 해당 장비 랙으로 카메라가 이동하고 장비 모달이 에러 포트를 하이라이트한 상태로 열림.
4 크로스-노드 자동 전환 Interaction
에러 장비가 현재 노드가 아닌 다른 노드 소속일 경우, 해당 노드로 자동 전환 후 포커싱.

1-5 환경 센서 모니터링 위젯

화면 설명

본 화면은 환경 센서 모니터링 위젯 기능과 관련된 동작 및 상태를 표시합니다. 주요 기능으로 [온도/습도 위젯 UI, 게이지 바 색상 단계, 물방울 아이콘, 노드 행 클릭] 등을 포함하고 있습니다.

마커 드래그 이동 / 리사이징 (박스 우측 하단) / 삭제 (우클릭)

UI 요소 설명

1 온도 게이지 바 Panel
노드별 온도를 15°C~35°C 범위로 정규화. 27°C 이상 주황, 31°C 이상 빨강 그라디언트로 위험도 직관 표시.
2 습도 물방울 아이콘 Panel
노드별 습도(%)를 물방울 아이콘의 채움 레벨로 시각화.
3 노드 행 클릭 전환 Interaction
위젯의 노드 행을 클릭하면 해당 노드로 3D 씬이 즉시 전환됨.

1-6 랙 정보 패널 (Device Panel)

화면 설명

본 화면은 랙 정보 패널 (Device Panel) 기능과 관련된 동작 및 상태를 표시합니다. 주요 기능으로 [우측 패널 레이아웃, 랙 이름/U 용량, 슬롯별 장비 타일, 빈 슬롯 표시, 장비 클릭 동작] 등을 포함하고 있습니다.

마커 드래그 이동 / 리사이징 (박스 우측 하단) / 삭제 (우클릭)

UI 요소 설명

1 랙 정보 헤더 Header
랙 이름, U 용량(예: 32U), 소속 노드 뱃지 등 랙의 기본 정보 표시.
2 장비 슬롯 타일 리스트 List
랙 내 전체 슬롯을 U 단위로 나열. 장비가 장착된 슬롯은 SVG 썸네일과 모델명 표시, 빈 슬롯은 Available 표시.
3 장비 클릭 → 상세 모달 Interaction
장착된 장비 타일 클릭 시 장비 상세 모달(Device Modal)이 열려 스펙·포트 현황 조회 가능.
4 수정 모드 드래그 배치 Interaction
Edit Mode에서는 장비 타일을 드래그하여 슬롯 간 재배치하거나, 등록 장비를 드래그하여 빈 슬롯에 장착 가능.

1-7 장비 상세 모달 (Device Modal)

화면 설명

본 화면은 장비 상세 모달 (Device Modal) 기능과 관련된 동작 및 상태를 표시합니다. 주요 기능으로 [장비 스펙 정보(IP/MAC/모델명 등), SVG 프리뷰, 포트 상태 툴팁, 에러 포트 마커, 양면 표시, 기본 표시 면 라벨] 등을 포함하고 있습니다.

마커 드래그 이동 / 리사이징 (박스 우측 하단) / 삭제 (우클릭)

UI 요소 설명

1 장비 스펙 헤더 Header
장비명, 유형 뱃지(Router/Switch/Server), 소속 랙, 제조사, 모델명, IP, MAC 주소 표기.
2 SVG 시각화 영역 Graphics
장비 전면부·후면부 외관 SVG 렌더링. 삽입된 카드 형상이 합성된 고해상도 프리뷰 제공.
3 앞면/뒷면 & 기본 라벨 Badge
양면 모델은 앞면·뒷면을 상하로 동시 표시. 기본 라벨로 텍스처·썸네일 기준 면 표시.
4 포트 호버 툴팁 Tooltip
SVG 포트 영역에 마우스 호버 시 포트 번호·이름·연결 상태가 툴팁으로 즉시 표시됨.
5 에러 포트 색상 마커 Floating UI
에러 포트 위치에 위험도별 색상 마커(빨강·주황·노랑·파랑) 오버레이. 문제 포트를 직관적으로 파악 가능.

1-8 다크/라이트 테마 전환

화면 설명

본 화면은 다크/라이트 테마 전환 기능과 관련된 동작 및 상태를 표시합니다. 주요 기능으로 [테마 토글 버튼 위치, 전환 전/후 3D 환경 변화] 등을 포함하고 있습니다.

마커 드래그 이동 / 리사이징 (박스 우측 하단) / 삭제 (우클릭)

UI 요소 설명

1 테마 토글 버튼 Switch
좌측 상단의 Light/Dark 전환 토글. 클릭 즉시 UI 전체와 3D 환경이 동시에 테마 전환됨.
2 3D 환경 테마 연동 3D Effect
다크 모드 시 야간 조명·어두운 배경, 라이트 모드 시 주간 조명·밝은 배경으로 가상공간이 실시간 전환됨.

2-1 수정 모드 진입 & 툴바

화면 설명

본 화면은 수정 모드 진입 & 툴바 기능과 관련된 동작 및 상태를 표시합니다. 주요 기능으로 [Edit Mode 토글 위치, 상단 툴바 버튼 배치(Save, Undo/Redo, Sample, Reset, 장비관리, 모델관리, 포트마법사), 사이드바 구성] 등을 포함하고 있습니다.

마커 드래그 이동 / 리사이징 (박스 우측 하단) / 삭제 (우클릭)

UI 요소 설명

1 Edit Mode 토글 Switch
상단 바의 ON/OFF 토글. 활성화 시 수정 모드에 진입하며 상단 툴바와 좌측 편집 패널이 표시됨.
2 상단 툴바 버튼 Button
Save, Undo/Redo, Sample, Reset, 장비관리, 모델관리, 포트마법사 등 주요 액션 버튼 배치.
3 좌측 편집 사이드바 Sidebar
계층 트리, 가상공간 설정, Scene Objects 리스트 등 편집 도구가 탭/아코디언으로 구성됨.
4 접이식 사이드바 Panel
사이드바를 아이콘 뷰로 최소화(Fold) 가능. 접힌 상태에서 아이콘 클릭 시 플로팅 패널이 오버레이됨.

2-2 가상공간 설정

화면 설명

본 화면은 가상공간 설정 기능과 관련된 동작 및 상태를 표시합니다. 주요 기능으로 [우측 '가상공간' 패널, W/D 입력, 3D공간 제작 버튼, 와이어프레임 가이드 라인] 등을 포함하고 있습니다.

마커 드래그 이동 / 리사이징 (박스 우측 하단) / 삭제 (우클릭)

UI 요소 설명

1 가상공간 설정 패널 Panel
공간의 가로(W)·세로(D) 사이즈를 수치 입력. 값 변경 후 공간이 실시간 렌더링 반영.
2 3D공간 제작 버튼 Button
