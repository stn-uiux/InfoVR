arcVRack 기능 요약 명세서

대상 독자: 서버실 운영자 / 시스템 담당자
버전: v1.0 (2026-08)

🔧 필수 구성 (초기 설정 순서)

아래 순서대로 설정을 완료해야 정상적인 운영이 가능합니다.

1. 계층 구조 생성 (전산실 등록)

관리할 물리적 공간 구조를 트리 형태로 먼저 정의합니다.

항목 내용
구성 단위 그룹 → 사이트 → 전산실(Room) → 구역(Zone)
기능 노드 추가 / 이름 변경 / 삭제 / 드래그 이동
비고 전산실(Room) 단위로 랙과 장비가 귀속됩니다

2. 모델 등록 (+ 포트맵핑 SVG 이미지 생성)

랙에 탑재할 장비의 외관 모델을 사전 등록합니다. 이후 장비 등록 시 선택하여 사용합니다.

항목 내용
모델 유형 단일형(Non-card) / 섀시형(Card-based)
외관 정의 카드 슬롯 그리드, 행·열 수, 간격, 카드 조합
타입 관리 같은 모델에 카드 조합이 다른 타입(Variant) 복수 등록 가능
포트맵핑 포트맵핑 마법사 실행 → SVG 이미지 자동 생성 및 저장 (필수)
썸네일 저장 시점에 WebP 썸네일 자동 생성 (3D맵, 모델목록, 타입목록 공통 사용)

3. 장비 등록

실제 운용 중인 장비의 인벤토리 정보를 등록합니다.

항목 내용
필수 정보 장비명, IP 주소, MAC 주소
연결 정보 소속 전산실, 장비 모델(타입), 제조사, 면(Front/Back)
카드 구성 섀시형 모델 선택 시 슬롯별 카드 삽입 설정 가능
포트 모듈 포트별 모듈(트랜시버 등) 설정 가능

4. 랙 생성

등록된 장비를 전산실 3D 공간에 배치합니다.

항목 내용
랙 규격 24U / 32U / 48U 선택
배치 방식 그리드 에디터에서 드래그로 위치 설정
장비 탑재 랙 내 U 위치 지정 후 등록 장비 선택
정렬 면대면 자동 배치 지원
방향 0° / 90° / 180° / 270° 회전

5. 가상공간 설정 (선택)

전산실별로 3D 가상공간 시각화 환경을 커스터마이징합니다.

항목 내용
활성화 전산실 단위로 개별 활성화/비활성화
환경 설정 바닥·벽·천장 색상, 안개, 조명 밝기, 블룸 효과
공간 크기 전산실 가로·세로 크기(cm) 수동 조정 또는 자동 계산
테마 다크 / 라이트 모드 전환

6. 3D 오브젝트 배치 (선택)

기둥, 공조기, 소화기 등 전산실 내 부속 시설물을 3D 모델로 배치합니다.

항목 내용
포맷 GLB / GLTF 3D 파일 임포트
조작 위치(XYZ), 회전(Y축), 스케일 조정
목적 현실 공간과의 1:1 시각화 정밀도 향상

7. 씬 오브젝트 관리 (선택)

3D 공간에 배치된 모든 오브젝트(랙 + 3D 모델)를 목록으로 관리합니다.

항목 내용
기능 오브젝트 선택, 잠금/잠금해제, 삭제
시각화 씬 내 오브젝트 하이라이트 연동

8. 환경 내보내기 / 불러오기

전산실 구성 전체를 파일로 저장하거나 복원합니다.

항목 내용
내보내기 랙, 장비, 3D 오브젝트 포함 JSON 파일 저장
불러오기 JSON 파일을 통한 환경 복원
용도 백업, 다른 PC로 이전, 팀 간 공유

📊 운영 기능

구성 완료 후 일상적인 전산실 모니터링 및 운영에 사용하는 기능입니다.

1. 계층 구조 트리

좌측 패널에서 그룹→사이트→전산실 구조를 트리 형태로 탐색합니다.

  • 노드 클릭 시 해당 전산실 3D 화면으로 즉시 전환
  • 장애 발생 전산실은 아이콘 강조 표시

2. 랙 상단 장애 표출

3D 공간 뷰에서 문제가 있는 랙을 즉시 식별할 수 있습니다.

  • 장애 심각도에 따라 랙 상단에 색상 배지(Critical / Major / Minor / Warning) 표시
  • 정상 랙과 시각적으로 명확히 구분

3. 랙 선택 시 자동 포커싱

랙을 클릭하면 카메라가 해당 랙으로 자동 이동합니다.

  • 선택된 랙 하이라이트 효과
  • 랙 내 장비 목록 및 탑재 현황 우측 패널에 표시

4. 장비 선택 시 장비 상세 및 장애 정보

랙 내 장비를 클릭하면 장비 상세도(SVG)와 포트 상태를 확인합니다.

  • 장비 전면/후면 SVG 뷰 전환
  • 포트 색상으로 정상(초록) / 장애(빨강) 즉시 구분
  • 장애 포트 클릭 시 에러 상세(레벨, 메시지) 표시

5. 캐러셀

랙 선택 후 다음 랙으로 순차 탐색이 가능합니다.

  • 이전 / 다음 버튼으로 랙 간 빠른 이동
  • 전산실 내 전체 랙을 순서대로 점검할 때 활용

6. 에러 상태 모니터링

전산실 또는 전체 인프라의 장애 현황을 집계하여 표시합니다.

  • 심각도별(Critical / Major / Minor / Warning) 카운트 표시
  • 장애 장비 목록 드릴다운 제공

7. 환경 센서 모니터링

전산실의 온도·습도 등 환경 데이터를 시각화합니다.

  • 센서 데이터 수집 및 임계치 초과 알림
  • 시계열 트렌드 차트 제공

8. 다크 / 라이트 모드

전체 UI 테마를 다크 / 라이트로 전환합니다.

  • 사용자 설정 유지(localStorage)
  • 3D 가상공간 조명 설정과 독립적으로 동작

✨ 선택 기능

arcVRoom (3D 공간 제작)

전산실 공간을 실제 도면 기반으로 3D로 구현하는 확장 기능입니다.

항목 내용
용도 실제 전산실 구조(벽, 문, 창문, 복도)를 3D로 재현
방식 도면 이미지 임포트 후 공간 요소 배치
연동 arcVRack 랙 배치 데이터와 통합 표시
목적 현장 방문 없이 전산실 레이아웃 파악, 신규 장비 도입 시뮬레이션

본 문서는 arcVRack v1.0 기준으로 작성되었습니다.
